# carcare

동네 자동차 정비소 탐색, 여러 업체 견적 요청, 자동차 용품 구매, 정비 예약을 한곳에서 제공하는 자동차 케어 플랫폼의 첫 화면입니다.

## 시작하기

`index.html`을 브라우저에서 열면 별도 설치 없이 확인할 수 있습니다. 현재 업체·상품 데이터는 화면 시연을 위한 샘플이며, 견적·예약·장바구니 입력은 프런트엔드 상호작용으로 동작합니다.

## 주요 화면

- 주변 정비소 카드와 서비스별 필터, 검색
- 업체별 견적 요청 폼
- 정비 예약 신청 폼
- 동네 업체 상품 카드와 장바구니 알림
- 업체 파트너 등록 진입점

## 다음 단계

실서비스 운영에는 회원 인증, 업체/상품 관리 화면, 데이터베이스와 API, 지도 및 위치 검색, 결제·예약 가능 시간 관리가 필요합니다.
