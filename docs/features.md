# 제품 기능

## 운전자

- 현재 위치 또는 동네·업종·키워드로 정비·세차·타이어·전기차 업체를 찾습니다.
- 차량과 필요한 작업을 한 번 등록해 여러 근처 업체의 비교 견적을 받습니다.
- 업체 서비스와 가능한 시간을 골라 정비 예약을 요청하고 상태 변경을 확인합니다.
- 업체가 등록한 자동차 용품을 구매하고 주문·배송 상태를 확인합니다.
- 작업 후 리뷰를 남기고 자주 찾는 업체를 저장합니다.

## 자동차 업체

- 업체 정보와 영업 지역·위치·전문 업종을 등록하고 운영자 승인을 받습니다.
- 서비스 가격, 예상 소요 시간, 예약 가능 시간을 관리합니다.
- 서비스 요청을 확인하고 금액과 작업 범위가 포함된 견적을 보냅니다.
- 예약을 확정·변경·거절하고 방문 이력을 관리합니다.
- 실물 상품과 서비스 이용권을 판매하고 재고·주문을 처리합니다.

## 플랫폼 운영

- 업체 등록 승인, 회원과 콘텐츠 관리, 신고·문의 대응, 거래 현황을 확인합니다.
- 결제·수수료·정산 정책은 결제 사업자와 운영 정책을 정한 뒤 별도 모듈로 붙입니다.

초기 화면과 API는 도메인의 시작점입니다. 지도 SDK, 회원 인증, 실결제, 파일 업로드, 알림 발송은 아직 외부 계정과 운영 정책에 연결되지 않았습니다.
