# 기능 현황

## 주소별 화면

- `gageyo.com`: 가게요 서비스 소개와 앱 진입 링크
- `app.gageyo.com`: 자동차 파트너 검색, 카테고리·지역 필터, 견적 요청, 예약, 상품 장바구니·주문, 주문 및 견적 UUID 조회
- `partner.gageyo.com`: 파트너 키 로그인, 견적 답변, 예약 상태 변경, 상품 등록·수정, 주문 항목 확인
- `admin.gageyo.com`: 업체 승인·중지, 파트너 키 발급, 견적·예약 조회, 상품·주문 상태 관리, 카테고리 관리

## 현재 구현 범위

- MariaDB에 업체, 카테고리, 견적 요청·제안, 예약, 상품, 주문을 저장합니다.
- 승인된 업체와 판매 중 상품만 고객 검색 API에 표시합니다.
- 주문 접수 시 재고를 잠그고 차감하며 주문 상태를 저장합니다.
- 운영자 요청은 `ADMIN_API_KEY`로 보호합니다. 업체별 파트너 키 원문은 발급 시 1회만 반환하며 DB에는 SHA-256 해시만 보관합니다.
- 파트너 API는 키에 연결된 업체 범위로 예약·상품·주문 자료를 제한합니다.

## 아직 필요한 기능

- 고객 회원 가입·로그인, 본인 확인, 고객별 견적·예약·주문 내역
- 파트너 사업자 등록 신청서와 업체 정보 변경 승인 절차
- PG 결제·환불·정산, SMS/이메일 알림
- 지도 SDK와 GPS 기반 반경 검색, 리뷰 작성·검증, 이미지 업로드
- 여러 판매자가 한 장바구니 주문을 처리하는 분할 배송·정산

주문 화면은 현재 결제 없이 `payment_pending` 주문을 접수합니다. 테스트 데이터와 외부 결제 없이 실제 거래 서비스로 운영할 수 있는 상태는 아닙니다.
