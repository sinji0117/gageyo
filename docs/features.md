# 기능 안내

가게요에는 네 화면과 세 종류의 사람이 있습니다.

| 누구 | 어디서 | 하는 일 |
| --- | --- | --- |
| **운전자(고객)** | `app.gageyo.com` | 업체 찾기, 견적 요청·비교·선택, 방문 예약, 자동차 용품 구매·방문 장착, 리뷰 |
| **업체(파트너)** | `partner.gageyo.com` | 입점 신청, 업체 정보·사진·영업시간, 서비스, 견적 답변, 예약 처리, 상품 판매·발송, 리뷰 답글, 정산 |
| **운영자** | `admin.gageyo.com` | 입점 심사, 업체·회원 관리, 정보 변경 승인, 주문·입금·환불, 정산 지급, 문의·신고, 공지, 설정 |
| (소개) | `gageyo.com` | 서비스 소개, 파트너 입점 안내, 자주 묻는 질문 |

## 고객 화면 (app.gageyo.com)

### 업체 찾기

- 검색어(상호·지역·주소·분야), **서비스 분야**(카테고리), **지역**(구·동)으로 찾습니다.
- **내 주변 업체 보기**: 브라우저 위치를 허락하면 반경(3·5·10·20·50km) 안의 업체를 **가까운 순**으로 보여 줍니다. 거리는 서버가 계산합니다.
- 정렬: 평점순 · 리뷰 많은 순 · 가까운 순 · 새로 입점.
- 카드에는 대표 사진(없으면 상호 첫 글자 그림), 평점·리뷰 수, 영업시간·휴무일, 거리, 분야가 보입니다.
  예전처럼 실제 업체가 아닌 사진을 업체 사진처럼 보여 주지 않습니다.
- 첫 화면의 업체 수·평균 평점·리뷰 수는 실제 숫자(`/api/stats`)입니다. 데이터가 없으면 숫자를 숨깁니다.

### 업체 상세 (`/?shop={업체ID}` 로 바로 열림)

- 사진(대표 + 업체 사진 최대 12장), 소개, 주소, 전화, 사업자 정보, 영업시간·휴무일
- **지도 링크**: 카카오맵·네이버 지도 검색, 좌표가 있으면 카카오맵 길찾기 (지도 SDK 키 없이 동작)
- 서비스와 시작 가격·소요 시간 → 서비스별 **예약** 버튼
- 이 업체의 상품 (바로 장바구니에 담기)
- 리뷰: 별점 분포, 작성자 이름 가림(김**), 이용 서비스, 사장님 답글, 10개씩 더 보기
- **관심 업체** 저장(로그인), 공유(주소 복사), 업체·리뷰 **신고**

### 견적 요청 → 비교 → 선택 → 예약

1. 서비스 분야, 지역, 차량(내 차량에서 고르기), 요청 내용, 연락처를 적어 요청합니다. 비회원도 됩니다.
2. 분야(업체가 고른 분야 중 하나와 같음, `기타`는 모든 업체)와 지역(요청 지역에 업체의 구·군이 들어 있음)이 맞는 **승인된 업체**에 알림 메일이 갑니다 (최대 30곳).
3. 업체들이 금액·작업 내용·유효 기간을 담아 견적을 보냅니다. 업체에는 견적을 보내기 전까지 고객 연락처가 가려져 보입니다.
4. 고객은 받은 견적을 금액순으로 비교합니다 (업체 평점·리뷰 수 함께). 회원은 메일로 알림을 받고 마이페이지에 쌓입니다.
   비회원은 요청 번호와 연락처로 [주문·예약 조회 → 견적]에서 봅니다 (이 브라우저에서 요청한 것은 목록으로도 보임).
5. **이 견적 선택** → 다른 견적은 '선택 안 됨'이 되고, 고른 업체 예약 신청서가 차량·이름·연락처가 채워진 채로 열립니다.
6. 요청은 **14일** 동안 받으며, 지나면 자동으로 마감으로 보입니다. 받는 중에는 고객이 취소할 수 있습니다.

### 방문 예약

- 서비스(선택), 날짜·시간, 차량, 이름·연락처, 요청 사항을 적어 신청합니다. 비회원도 됩니다.
- 서버가 확인합니다: 승인된 업체인지, 서비스가 그 업체 것인지, **영업시간 안·휴무일 아님**, **지금부터 30분 이후 ~ 90일 이내**, 같은 연락처로 같은 시간 중복 신청이 아닌지.
- 상태: `신청` → `확정` → `완료` (업체 거절 `거절`, 고객·업체 취소 `취소`). 업체가 바꾸면 회원에게 메일이 갑니다.
- 고객은 방문 시간 전에 신청·확정 상태의 예약을 취소할 수 있습니다 (비회원은 예약 번호 + 연락처).
- 완료된 예약에만 **리뷰**를 쓸 수 있습니다 (예약당 한 번, 1~5점, 5~1000자). 고치고 지울 수 있습니다.

### 자동차 용품 · 장바구니 · 주문

- 분류·검색·가격순 정렬, 상품 상세(정가 대비 할인율, 재고, 판매 업체), 장바구니(이 브라우저에 저장).
- **받는 방법**
  - 택배: 여러 업체 상품을 한 번에 주문할 수 있고, 업체마다 따로 보냅니다. 배송 주소는 **주소 검색**(다음 우편번호, 키 필요 없음)으로 채웁니다.
  - **업체 방문 장착**: 한 업체 상품만, 방문 희망 시간을 고르면 그 업체에 **예약 신청이 함께 만들어집니다**.
- **결제**: 카드·간편결제(토스페이먼츠 결제창), 무통장입금(운영자가 정한 계좌·기한 안내), 둘 다 설정하지 않은 서버에서는 '업체와 직접 결제(주문만 접수)'.
- 금액은 서버가 상품 가격으로 다시 계산합니다. 주문하는 순간 재고가 줄고(0이면 자동 품절), 취소하면 돌아옵니다.
- 결제하지 않은 주문은 자동 취소되어 재고가 돌아옵니다: 카드는 2시간, 무통장은 입금 기한 + 24시간 ([결제 안내](payments-toss.md#결제하지-않은-주문-자동-취소)).
- 주문 상세: 상태, 상품별 업체·배송 상태·**배송 조회 링크**(택배사 12곳), 입금 계좌, 결제 다시 하기, 결제 전 취소.
- 비회원은 주문 번호 + 연락처로 조회·취소합니다. 결제 후 취소·교환은 고객센터 문의로 운영자가 처리합니다.

### 마이페이지 (로그인)

- 예약(취소·리뷰 쓰기), 견적(받은 견적 수·최저가), 주문, 내 후기, 관심 업체, **내 차량**(최대 10대, 견적·예약 때 바로 고름), 문의
- 내 정보(이름·연락처), 비밀번호 바꾸기(다른 기기 로그아웃), **탈퇴**
  - 배송 중인 주문이나 다가오는 예약이 있으면 탈퇴할 수 없습니다.
  - 주문·예약 기록은 거래 확인을 위해 남고, 이메일·이름·연락처·비밀번호는 지워집니다. 같은 이메일로 다시 가입할 수 있습니다.

### 계정

- 가입: 이름·이메일·비밀번호(10자 이상)·연락처(선택). 메일 설정이 있으면 **이메일 6자리 코드 인증**(10분 유효, 60초에 한 번·1시간 5번·IP 1시간 30번, 5번 틀리면 폐기).
- 로그인 5번 틀리면 15분 잠금, 같은 IP 는 15분에 50번까지.
- **비밀번호 찾기**: 메일로 30분짜리 일회용 링크. 가입 여부는 알려 주지 않습니다.

### 고객센터

- 1:1 문의: 비회원은 이름·이메일을 넣고, 답변을 볼 **비밀 링크**(48자)를 메일로 받습니다. 회원은 마이페이지 → 문의.
- 운영자가 답하면 메일이 가고, 이어서 물으면 다시 '답변 대기'가 됩니다.
- 신고: 업체·리뷰·상품 (사유 선택 + 내용)
- 공지: 화면 아래쪽 (운영자가 고객 대상으로 올린 것, 고정 공지 먼저)
- 아래쪽에 고객센터 전화·이메일과 사업자 정보(운영자가 설정) 표시

## 파트너 센터 (partner.gageyo.com)

### 입점 신청과 로그인

- **입점 신청** = 담당자 계정(이메일·비밀번호·이름·연락처, 메일 설정 시 이메일 코드 인증) + 업체 정보
  (상호, 업체 전화, **서비스 분야 여러 개**(최대 8, 첫 번째가 대표), 지역(구·군), 주소, **사업자등록번호(검증 숫자 확인)**, 대표자, 소개, 위치(선택, '현재 위치' 버튼)).
- 신청하면 바로 로그인되고 업체는 **승인 대기**입니다. 운영자에게 알림 메일이 갑니다.
  승인 전에도 업체 정보·사진·서비스·상품을 미리 준비할 수 있고, 견적·예약·주문·정산 메뉴는 승인 후 열립니다.
- 승인·반려·중지되면 메일로 알립니다. 반려되면 사유가 보이고, 고쳐서 다시 심사를 받을 수 있습니다.
- 비밀번호 찾기·설정: 운영자가 대신 등록한 업체도 여기서 처음 비밀번호를 정합니다.
- **예전 파트너 키**(운영자가 발급한 키)로도 계속 접속할 수 있습니다. 화면에 계정으로 옮기라는 안내가 보입니다.

### 대시보드

오늘 예약·확정 대기, 다가오는 확정 예약, 보낼 상품, 이번 달 판매액, 30일 견적·선택 수, 답글 없는 리뷰, **업체 준비 체크리스트**
(소개·영업시간, 사진, 서비스, 위치), 새 견적 요청, 다가오는 예약, 공지. 왼쪽 메뉴에 처리할 건수가 숫자로 보입니다.

### 견적

- **견적 요청**: 분야·지역이 맞고 아직 답하지 않은 14일 안의 요청. 다른 업체 견적 수도 보입니다.
- **견적 보내기** 창에서 금액·작업 내용·유효 기간을 넣습니다 (예전에는 브라우저 입력창 두 개였음).
- **보낸 견적**: 상태(보냄·고객 선택·선택 안 됨·철회). 고객이 고르면 이름·연락처가 보이고 메일이 옵니다. 고르기 전에는 철회할 수 있습니다.

### 예약 일정

확정 대기 · 다가오는 예약 · 지난 예약 · 전체. 신청 → **확정**/거절(사유 필수), 확정 → **작업 완료**/취소(사유 필수).
신청을 바로 완료로 바꿀 수도 있습니다(방문 즉시 작업). 상품 방문 장착 예약은 표시가 붙습니다.

### 서비스

이름·설명·시작 가격·소요 시간·정렬·보이기. 고치고 지울 수 있으며, 예약에 쓰인 서비스는 기록을 위해 숨김 처리됩니다.

### 상품

대표 이미지 올리기, 상품명·분류(전에 쓴 분류 추천)·설명·판매가·정가·재고·상태(판매·준비 중·숨김). 재고 0이면 자동 품절.
**운영자가 판매 중지한 상품은 파트너가 다시 열 수 없습니다** (예전에는 수정만 해도 판매 중으로 돌아갔음).
주문된 적 없는 상품은 지우고, 주문 기록이 있으면 숨깁니다. 판매 수량이 함께 보입니다.

### 주문·배송

- 결제가 끝난 주문 중 **우리 업체 상품 줄만** 보입니다 (예전에는 다른 업체 상품까지 합친 주문 전체 금액이 보였음).
- 준비 중 → **발송 처리**(택배사 12곳 + 운송장 번호, 직접 배송은 번호 없이) → 배송 완료. 방문 장착 주문은 **장착 완료**로 바로 끝내고 예약도 완료로 바뀝니다.
- 발송하면 고객에게 배송 조회 링크가 담긴 메일이 갑니다. 주문 전체 상태는 줄 상태로 자동 계산됩니다.

### 리뷰

모든 리뷰와 답글 달기·고치기·지우기. 운영자가 숨긴 리뷰는 표시가 붙습니다.

### 정산

연도별·월별 매출, 수수료, 지급액, 주문 수, 지급 여부(지급일·지급액). 지급 뒤 환불 등으로 금액이 바뀌면 표시됩니다.
→ [정산과 수수료](payments-toss.md#정산)

### 업체 정보

- 바로 반영: 소개, 업체 전화, 영업시간, **정기 휴무 요일**, 위치(현재 위치 버튼), 대표 사진, 업체 사진(최대 12장, 대표로 지정·삭제)
- 운영자 승인 뒤 반영(**변경 요청**): 상호, 서비스 분야, 지역, 주소, 사업자등록번호, 대표자. 심사 중인 요청이 있으면 새로 요청할 수 없습니다.
  승인 전·반려된 업체는 바로 고치고 다시 심사를 받습니다.

### 공지·문의

운영자 공지(파트너 대상·전체 대상)와 운영자에게 1:1 문의(대화형, 답변 메일).

## 운영자 화면 (admin.gageyo.com)

### 로그인과 보안

- 서버 설정 `ADMIN_EMAILS` 에 있는 이메일만 로그인합니다. 처음에는 **비밀번호 설정 메일 받기**로 비밀번호를 정합니다
  (계정이 없으면 운영자 계정을 만듭니다. 메일 설정이 없으면 API 로그에 링크가 남습니다).
- **2단계 인증(OTP)**: 내 보안에서 QR(브라우저에서 만듦)을 OTP 앱으로 찍고 코드로 확인해 켭니다. 켜면 로그인 때 코드가 필요하고, 같은 코드는 한 번만 쓸 수 있습니다.
  꺼져 있으면 화면 위에 켜라는 안내가 보입니다. 비밀값은 DB 에 암호화(`DATA_KEY`)해서 둡니다.
- 운영자 세션은 12시간입니다. 비상용 `ADMIN_API_KEY` 로도 들어올 수 있습니다 (작업 기록에는 `api-key`).
- 로그인 5번 실패 15분 잠금.

### 대시보드

승인 대기 업체, 정보 변경 요청, 답변 대기 문의·신고, 입금 확인 대기, 30일 거래액·결제 건수, 보낼 상품, 승인·중지 업체, 고객·신규 회원,
받는 중인 견적, 이번 달 예약, 30일 리뷰, 파트너 계정 — 누르면 해당 화면으로 갑니다. **월별 거래액·수수료 차트**(6개월), 최근 작업 기록.
예전 화면의 '새로고침'은 숫자를 다시 받지 않았고 회원·신고 메뉴는 준비 중이었습니다.

### 업체 관리

- 상태별(승인 대기·승인·반려·중지·전체) 목록, 검색(상호·지역·이메일·사업자번호), 변경 요청 수 표시
- 상세: 분야, 주소·좌표, 사업자 정보(사업자 조회 링크), 영업시간, 담당자(상태·최근 로그인), 서비스·상품·예약·견적 수, 사진, 변경 요청 기록
- **승인**·**반려**(사유 필수, 메일)·**이용 중지**(사유 필수, 메일)·다시 승인
- **정보 고치기**: 모든 정보를 바로 수정 (작업 기록)
- **비밀번호 설정 링크**: 업체 주인 계정에 파트너 센터 비밀번호 설정 링크를 보냄 (예전 파트너 키 업체를 계정으로 옮길 때). 메일 설정이 없으면 화면에 링크를 보여 줌
- **파트너 키 발급/재발급**(예전 방식, 한 번만 보임, 재발급하면 이전 키 무효)
- **업체 직접 등록**: 전화·방문으로 받은 업체를 등록하고 주인 계정을 만들어 설정 링크를 보냄

### 정보 변경 요청

지금 값과 바뀔 값을 나란히 보고 승인(바로 반영) 또는 반려(사유, 메일).

### 견적·예약·리뷰

- 견적: 상태별 목록, 검색, 스팸 요청 **마감**
- 예약: 상태별 목록, 검색, 분쟁 시 상태 변경(사유, 작업 기록)
- 리뷰: 공개·숨김 목록, **숨기기**(사유, 업체 평점에서 빠짐)·다시 공개

### 상품·주문·정산

- 상품: 모든 업체 상품, 상태별·검색, 재고·판매 수량, **판매 중지**(사유)·판매 재개
- 주문: 상태·결제 수단별, 검색(주문번호 앞자리·주문자·연락처·입금자명). 상세에서
  - 무통장 **입금 확인** → 결제 완료(줄마다 수수료 고정, 업체에 새 주문 메일)
  - **카드 결제 확인**: 결제창 승인 뒤 화면이 끊겨 결제 대기로 남은 카드 주문을 토스에서 찾아 결제 완료로 맞춤
  - **주문 취소**(사유): 발송된 상품이 있으면 막음. 카드 결제는 토스에서 **자동 전액 환불**, 무통장은 환불 상태로 바꾸고 직접 돌려주라고 안내. 재고·방문 예약 되돌림. 고객·업체 메일
  - 결제 수단 없이 접수한 주문은 '결제 완료로'
- 정산: 월을 고르면 업체별 매출·수수료·지급액·주문 수, 합계, **지급 완료 기록**(끝난 달만, 메모), 기록 지우기, **CSV 내려받기**

### 회원 관리

고객·파트너·운영자 탭, 검색, 목록 연락처 가림, 상세(최근 로그인 IP, 활동 수, 소유 업체), **정지**(사유 필수, 바로 로그아웃)·해제. 운영자 계정은 정지할 수 없습니다.

### 문의·신고

고객 문의·파트너 문의·신고 탭(답변 대기 수), 왼쪽 목록·오른쪽 대화. 답변(메일 발송), 종료·다시 열기. 신고는 대상 관리 화면으로 바로 이동.

### 공지

대상(전체·고객·파트너), 제목·내용, 맨 위 고정, 공개/숨김.

### 카테고리

그룹·이름·정렬·노출. 이름을 바꾸면 그 이름을 쓰던 **업체 분야도 함께 바뀝니다**. 업체가 쓰는 카테고리는 지울 수 없고 숨김으로 바꿉니다. 카테고리마다 쓰는 업체 수가 보입니다.

### 결제·운영 설정

- 카드 결제·메일·가입 인증이 켜졌는지 상태 카드
- **플랫폼 수수료율**(0~30%), **무통장 입금 계좌**(은행·계좌번호·예금주, 세 칸 모두 있어야 켜짐)·입금 기한, 고객센터 전화·이메일, 사업자 정보

### 작업 기록

승인·반려·중지·수정·정지·취소·환불·입금 확인·정산·설정·공지·카테고리·로그인·OTP 등 운영자 작업과 사유·IP. 대상별로 거르기.

## 주소 검색

주문서 배송 주소, 입점 신청·업체 정보·운영자 업체 등록의 주소 칸 옆 **주소 검색**을 누르면 다음(카카오) 우편번호 창이 열립니다.
고르면 도로명 주소가 채워지고 커서가 끝으로 가서 상세 주소를 이어 씁니다. 업체 주소를 고르면 **지역(구·군)도 자동으로** 채워집니다.
창을 열 수 없으면(차단·오프라인) 직접 입력합니다.

## 이미지 업로드

- JPG·PNG·GIF·WebP 만, 내용(매직 바이트)으로 형식을 확인하고 SVG 는 받지 않습니다.
- JPG·PNG 는 다시 저장하면서 **사진 위치(GPS) 같은 정보를 지우고**, 휴대폰 사진 회전을 바로잡고, 긴 변 2400px 를 넘으면 줄입니다.
- 한 장 최대 10MB(`UPLOAD_MAX_MB`), 파트너·운영자만 올림, 업체당 1시간 300장.
- `UPLOAD_DIR/{yyyymm}/{무작위 32자}.{확장자}` 에 저장, `/api/files/…` 로 열림(1년 캐시).
