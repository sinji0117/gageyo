# 테스트

GitHub Actions(`.github/workflows/ci.yml`)가 push·PR 마다 아래를 모두 돌립니다. MariaDB 는 서비스 컨테이너로 띄웁니다.

## 단위 테스트

```bash
cd backend && cargo test
```

| 크레이트 | 확인하는 것 |
| --- | --- |
| core | 설정(바인드 주소·이메일 목록·토스 키 짝·Rpanel 업로드 폴더), 오류 코드, 비밀번호·쿠키·IP 헤더, 가입 코드 규칙, OTP(RFC 6238 벡터), 암호화·HMAC, 이미지(다시 저장·크기 줄이기·SVG/가짜 이미지 거부·경로 모양), 입력 검사(전화·사업자번호 검증 숫자·좌표·거리·쪽수·LIKE 이스케이프·택배 조회 주소·수수료), 영업시간·휴무일·방문 가능 시간, 토스 승인·거절·취소·통신 오류(로컬 모의 서버) |
| workshop | 이름 가리기, 금액 표시, 예약 상태 흐름 |
| commerce | 주문 상태 계산, 상품 상태 규칙(운영자 판매 중지), 주문 줄 합치기·수량 한도, 결제 수단 고르기, 배송 상태 흐름, 정산 월 형식 |
| api | 사이트맵 XML 이스케이프 |

## 종단 검사 (실제 MariaDB)

```bash
docker compose -f docker-compose.dev.yml up -d mariadb
cd backend && cargo build -p gageyo-api && cd ..
DATABASE_URL=mysql://gageyo_user:devpass@127.0.0.1:3306/gageyo_db bash scripts/e2e.sh
```

스크립트가 토스 모의 서버(`scripts/mock_toss.py`)와 API 를 직접 띄우고(포트 18081·18090), curl 로 200여 가지를 확인합니다.
개발·CI 전용 DB 에서 돌리세요 (검사용 계정·업체·주문이 쌓입니다).

- 운영자 첫 설정(설정 링크 → 비밀번호 → 로그인), 링크 재사용 거부, `ADMIN_EMAILS` 밖 거부, 틀린 키 거부, **OTP 켜기 → 코드 없이 로그인 거부 → 코드로 로그인**
- 입점 신청(사업자번호 검증·중복 거부) → 승인 전 견적 메뉴 막힘·고객 화면에 안 보임 → 반려 사유 필수 → 승인 → 로그아웃·로그인
- 영업시간·휴무일, 서비스, 상품(정가 검사), **운영자 판매 중지 상품은 파트너가 못 엶**
- 분야 검색, **반경 검색·거리 계산**, 업체 상세(서비스·분야), 상품 검색
- 고객 가입·중복 거부·파트너 계정의 고객 로그인 거부, 내 차량, 관심 업체
- 견적: 없는 분야 거부, 분야·지역 맞는 업체에만 보임, 답하기 전 연락처 가림, 두 번 답하기 거부, 연락처·회원 확인, 선택, 두 번 선택 거부, 선택 후 연락처 공개
- 예약: 영업시간 밖·휴무일·지난 시간 거부, 견적 연결 예약, 같은 시간 중복 거부, 상태 흐름, 비회원 조회·취소, 거절 사유 필수
- 리뷰: 완료 예약에만, 두 번 거부, 평점 반영, 답글, 숨기면 평점에서 빠짐
- 주문(카드): 재고 초과 거부, 같은 상품 줄 합치기, 재고 차감, **금액 다르면 승인 거부**, 카드 거절 402, 승인, 새로고침 재승인, 파트너는 자기 몫만, 택배사 없이 발송 거부, 발송·배송 조회 주소, 비회원 조회, 발송된 주문 취소 거부
- 주문(무통장): 계좌 안내 → 입금 확인 → 운영자 취소(직접 환불 안내)·재고 복원 / 카드 결제 후 취소 → **자동 환불** / 재고 0 → 품절 → 취소 → 다시 판매
- 방문 장착 주문(예약 함께 생성, 시간 없으면 거부)
- 정산 금액, 이번 달 지급 처리 거부
- 정보 변경 요청 → 심사 중 중복 거부 → 승인 반영
- 이미지 올리기·열기, 가짜 이미지·로그인 없이 거부, 업체 사진·대표 사진 자동 지정
- 비회원 문의(비밀 링크 48자·틀린 링크 거부)·답변·이어 묻기·봇 칸, 리뷰 신고, 파트너 문의, 공지 대상 분리
- 회원 검색(연락처 가림)·정지(사유 필수, 즉시 로그아웃, 로그인 거부)·해제, 작업 기록, 대시보드, 쓰는 카테고리 삭제 거부, 예전 파트너 키, 사이트맵
- 비밀번호 재설정, **로그인 5번 실패 잠금**, 예약 있으면 탈퇴 거부, 탈퇴·재가입

## 화면 점검 (브라우저)

```bash
cd frontend && npm install && npm run build && cd ..
npm install --prefix /tmp/pw playwright-core
NODE_PATH=/tmp/pw/node_modules OUT=/tmp/ui-shots CHROME=$(which google-chrome) \
  DATABASE_URL=mysql://gageyo_user:devpass@127.0.0.1:3306/gageyo_db bash scripts/ui-smoke.sh
```

API 를 8081 에 띄우고 검사용 업체·사진·서비스·상품·고객·견적을 만든 뒤, 빌드한 네 화면을 `vite preview`(4173~4176)로 띄우고
Chrome 으로 고객 첫 화면·업체 상세·예약·상품·장바구니·주문서·견적·로그인·마이페이지·견적 비교·휴대폰 화면,
파트너 입점 신청·로그인·대시보드·각 메뉴, 운영자 로그인·대시보드·각 메뉴·업체 상세, 소개 페이지를 찍습니다.
**자바스크립트 오류**가 하나라도 나오거나 단계가 실패하면 실패로 끝납니다. 스크린샷은 `OUT` 폴더에 남습니다.
