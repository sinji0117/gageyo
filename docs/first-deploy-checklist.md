# 첫 배포 체크리스트

[Rpanel 배포 따라 하기](rpanel-setup.md)와 함께 위에서부터 차례로 표시하세요.

## 서버·저장소

- [ ] Rpanel 서버 메모리 4GB 이상 (Rust 릴리스 빌드), 디스크 여유 10GB 이상
- [ ] DNS: `gageyo.com` · `app` · `partner` · `admin` → 서버 IP
- [ ] 비공개 저장소면 앱마다 Deploy key 등록 (쓰기 권한 없이)

## API 앱

- [ ] 앱 폴더 `backend`, 바이너리 `gageyo-api`, 상태 확인 `/api/health`
- [ ] MariaDB 연결 → `DATABASE_URL` 확인
- [ ] `DATA_KEY` (`openssl rand -hex 32`) — **따로 안전한 곳에 적어 두기**
- [ ] `ADMIN_EMAILS`, `APP_URL` · `PARTNER_URL` · `ADMIN_URL`
- [ ] `SMTP_URL` · `MAIL_FROM` · `OPS_EMAIL` (보내는 도메인의 SPF·DKIM 설정)
- [ ] `TOSS_CLIENT_KEY` · `TOSS_SECRET_KEY` (처음엔 `test_` 키)
- [ ] 배포 후 로그에 `설정 오류` 가 없고 `메일: SMTP 사용` · `listening` 이 보임

## 화면 앱 네 개

- [ ] 앱 폴더 `frontend`, 빌드 명령·출력 폴더가 [표](rpanel-setup.md#6-화면-앱-네-개)와 같음
- [ ] 각 앱 API 연결 `gageyo-api` · `/api/`
- [ ] SSL 발급, https 리디렉션
- [ ] `https://app.gageyo.com/api/health` → `{"status":"ok"}`

## 운영자

- [ ] 운영자 화면 → 비밀번호 설정 메일 → 로그인
- [ ] **내 보안**에서 OTP 켜기
- [ ] 결제·운영 설정: 수수료율, 고객센터 전화·이메일, 사업자 정보, (선택) 무통장 계좌·입금 기한
- [ ] 상태 카드에서 카드 결제·메일·가입 인증이 켜졌는지
- [ ] 카테고리 확인·정리, 고객·파트너 대상 공지 하나씩

## 흐름 확인 (테스트 키로)

- [ ] 고객 가입(이메일 코드 도착) · 비밀번호 찾기 메일
- [ ] 파트너 입점 신청 → 운영자 승인 메일 → 서비스·상품·사진 등록 (주소 검색 동작)
- [ ] 고객 화면에서 업체 검색·상세·내 주변(휴대폰 위치 허용)
- [ ] 견적 요청 → 파트너 견적 → 고객 선택 → 예약 확정 → 완료 → 리뷰
- [ ] 상품 주문 → **토스 결제창에서 테스트 카드 결제** → 파트너 발송(운송장) → 배송 조회 링크
- [ ] 결제창에서 취소/실패 → 주문서로 돌아와 다시 결제
- [ ] 운영자 주문 취소 → 토스 상점관리자에서 **환불됨** 확인
- [ ] 무통장 주문 → 입금 확인 → 정산 화면 금액
- [ ] 비회원 주문·예약 조회, 1:1 문의 비밀 링크 메일
- [ ] 휴대폰에서 고객 화면 한 바퀴

## 운영 전환

- [ ] 토스 가맹 심사 완료 → `live_` 키로 바꾸고 재시작 → 소액 실제 결제·환불
- [ ] DB 백업 켜기, 복원 한 번 해 보기, 업로드 폴더 백업
- [ ] 개인정보 처리방침·이용약관 게시, 통신판매업 신고 번호를 사업자 정보에
- [ ] `/api/sitemap.xml` 을 검색 엔진(네이버 서치어드바이저·구글 서치 콘솔)에 등록
- [ ] 비상용 `ADMIN_API_KEY` 를 쓰지 않으면 비워 두기
