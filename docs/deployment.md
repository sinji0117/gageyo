# 배포 구성

Rpanel 또는 일반 리눅스 호스트에서 Rust API와 MariaDB를 운영하는 배포 설계 초안입니다. `deploy/rpanel.env.example`의 값은 이름만 있는 예시이며 비밀번호·호스트를 실제 환경의 비밀 값으로 설정해야 합니다.

배포 전에 프런트엔드 앱을 각각 빌드하고 정적 파일을 웹 서버 또는 API 정적 파일 서비스에 연결합니다. `VITE_API_URL`은 공개 API 주소로 지정합니다. 운영 환경에서는 HTTPS, 제한된 CORS 원본, DB 백업, 로그 보존, 인증·권한 검증, 결제 웹훅 검증을 먼저 설정해야 합니다.
